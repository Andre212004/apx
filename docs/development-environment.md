# Development Environment

The APX Development Environment is the official workspace for building APX.

It is separate from the Hub so that the Hub remains clean and focused on APX management.

## Purpose

The Development Environment contains tools used to design, build, test, document, and release APX.

Examples include:

- Git
- GitHub CLI
- Codex
- ChatGPT
- Brave
- IDEs
- compilers
- build tools
- test tools

## Boundary

Development activity belongs here, not in the Hub.

This includes:

- source code
- documentation drafts
- repository management
- experiments
- build outputs
- issue and pull request work

## Relationship to APX

The Development Environment is itself an APX Environment conceptually, but during the foundation phase it is also the place where the APX repository is maintained.

Implementation work should continue to respect the architecture-first process established in this repository.
