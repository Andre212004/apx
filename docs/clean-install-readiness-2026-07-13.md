## Installation Decision

Starting a real Arch installation now would produce a minimal Arch system but
not a functional APX orchestration layer. It would strand the user between a
formatted disk and unimplemented Hub/executor behavior. The correct decision is
therefore `blocked`, not “install and fix it live.”

The first safe user-visible milestone is a complete disposable-machine C0–C6
rehearsal. Only its exact successful artifacts and failure evidence may support
a real-machine dossier.
