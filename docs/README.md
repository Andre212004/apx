# APX Documentation

This directory contains the foundation documentation for APX.

The documentation is intentionally architecture-first. No implementation should be added until the repository clearly documents what APX is, what it is not, and how its core boundaries work.

## Documents

- [Architecture](architecture.md): system model, boundaries, and core decisions
- [Environments](environments.md): environment identity, storage, sessions, processes, and metadata
- [Hub](hub.md): the APX management environment and its strict responsibilities
- [Development Environment](development-environment.md): the official APX development environment
- [Repository](repository.md): repository organization and contribution rules for the foundation phase
