# APX Hub GTK prototype

This is a non-privileged GTK4/libadwaita shell around the pure `apx_hub` view
model. It uses fixture data, labels itself as demo data, disables every action,
and has no executor, filesystem, subprocess, package, session, or lifecycle
adapter. It is source input for the future `hub-hyprland-v1` role, not an
installed Host or Hub application.
